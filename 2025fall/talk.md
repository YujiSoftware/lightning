Java の LT を作って
------------
いいね！JavaのLT（ライトニングトーク）をそのまま使える形で作りました。想定時間は **7分〜8分（スライド8枚）**。そのまま発表できるスライド本文・発表メモ・デモ用コード・実行手順まで全部入っています。必要ならスライドの枚数や話す時間、対象（初心者／中級者）を変えて調整もできます。

## スライド3 — ネタ1：`var`で局所変数を簡潔に（60秒）

**ポイント**

* Java 10+ の `var` は型推論（局所変数のみ）
* 可読性を下げない範囲で使うとコードが短くなる

**例**

```java
// before
Map<String, List<String>> map = new HashMap<>();

// after
var map = new HashMap<String, List<String>>();
```

**発表メモ**：型が明らかなときに有用。メソッド署名やクラス変数には使えないことを強調。

---

## スライド4 — ネタ2：Stream の `toMap` で衝突を防ぐ（90秒）

**問題**：`Collectors.toMap` でキーが重複すると例外
**解決**：マージ関数を渡す

**例**

```java
import java.util.*;
import java.util.stream.*;

record Person(String name, int score) {}

public class ToMapSample {
    public static void main(String[] args) {
        var people = List.of(new Person("A", 10), new Person("B", 20),
                             new Person("A", 15));
        var map = people.stream()
            .collect(Collectors.toMap(
                Person::name,
                p -> p.score(),
                Integer::sum  // 衝突時は合算
            ));
        System.out.println(map); // {A=25, B=20}
    }
}
```

**発表メモ**：衝突処理のアイデア（合算、最新を採る、リストにするなど）を示す。

---

## スライド5 — ネタ3：`record` で簡潔なデータクラス（60秒）

**ポイント**

* Java 16+ の `record` は不変データクラスを簡潔に定義
* 自動で `equals/hashCode/toString` を生成

**例**

```java
public record Point(int x, int y) {}

var p = new Point(1, 2);
System.out.println(p); // Point[x=1, y=2]
```

**発表メモ**：BOILERPLATE が減ること、互換性（従来クラスに戻せる）を短く説明。

---

## スライド6 — 実演（デモ）：small program（120秒）

**やること**：先ほどの `ToMapSample` を実行して結果を見せる（合算されることをデモ）

**実行手順（端末）**

```bash
# ファイル作成
cat > ToMapSample.java <<'JAVA'
import java.util.*;
import java.util.stream.*;
record Person(String name, int score) {}
public class ToMapSample {
    public static void main(String[] args) {
        var people = List.of(new Person("A", 10), new Person("B", 20),
                             new Person("A", 15));
        var map = people.stream()
            .collect(Collectors.toMap(
                Person::name,
                p -> p.score(),
                Integer::sum
            ));
        System.out.println(map);
    }
}
JAVA

# コンパイル（Java 11+ を想定）
javac ToMapSample.java
java ToMapSample
```

**発表メモ**：実行して結果を見せる。失敗したらソースを直接表示して説明。
